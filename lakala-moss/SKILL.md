# 拉卡拉MOSS支付下单

通过拉卡拉MOSS统一支付接口(v3)发起支付订单，获取支付链接，用户扫码即可完成支付。

## 前置准备

- 安装依赖：`pip install requests>=2.28.0`
- 准备订单号（必须唯一）和支付金额（单位：分）

## 操作步骤

### 第一步：接收用户订单参数

必需参数：
- `order_no`：商户订单号（必须唯一）
- `total_amount`：支付金额（字符串，单位：分，如"1"=1分钱）

可选参数：
- `subject`：订单标题
- `remark`：交易备注
- `callback_url`：支付结果回调地址

### 第二步：调用下单脚本

```bash
python scripts/create_order.py --order-no "TEST001" --total-amount "1"
```

### 第三步：解析响应

脚本返回JSON结果，包含：
- `success`：是否成功
- `pay_url`：支付链接（用户点击完成支付）
- `order_no`：订单号
- `service_sn`：服务流水号

### 第四步：返回结果给用户

将支付链接呈现给用户，引导完成支付。

## 使用示例

### 示例1：发起1分钱测试订单
- 场景：用户想测试支付接口
- 输入：订单号 `TEST001`，金额 `1`
- 产出：支付链接
- 要点：演示环境使用固定测试商户号，不涉及真实资金

### 示例2：发起1元正式订单
- 场景：用户需要生成支付链接
- 输入：订单号 `20240101001`，金额 `100`
- 产出：支付链接
- 要点：金额单位是分，金额需转字符串

### 示例3：完整参数下单
- 场景：用户需要完整订单信息
- 输入：订单号、时间、金额、主题、备注、回调地址
- 产出：完整订单信息和支付链接
- 要点：回调地址需公网可访问

## 注意事项

### 演示环境
- 当前使用固定测试商户号（M00002042），不涉及加解签
- 仅用于接口测试和功能演示，不适用于生产环境
- 不处理真实资金

### 生产环境要求
- 必须使用真实商户号替换 M00002042
- 必须配置商户公钥/私钥进行签名验证
- 所有请求必须通过HTTPS加密传输
- 确保回调地址可公网访问且具备安全验证

### 通用注意
- 订单号必须唯一，重复会失败
- 金额单位为分，字符串形式传入
- 支付方式默认支持支付宝、微信、银联
- 订单有效期30分钟
